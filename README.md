# BrownBearAddon

BrownBearAddon is a Minecraft plugin designed to enhance your gameplay by allowing players to spawn brown bears with a simple command. This plugin is perfect for players who enjoy customizing their Minecraft world with unique entities and features.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/yourusername/BrownBearAddon/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Join your Minecraft server.
2. Use the command `/spawnbear` to spawn a brown bear at your current location.
